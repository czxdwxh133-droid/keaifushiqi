# 数据分析指标定义

## 复购率 / 回头客比例

复购率 = 购买次数 ≥ 2 次的用户数 / 有过购买记录的总用户数 × 100%
计算时只统计"已完成"状态的订单，排除已取消和已退款记录。
同义词：回头客占比、重复购买率、老客户比例、二次购买率。

## 客单价 / 平均订单金额

客单价 = 总销售额（已完成订单） / 已完成订单总数
反映每笔订单的平均消费金额。

## 退款率

退款率 = 已退款订单数 / 总订单数 × 100%
注意区分"退款率"（按订单数）和"退款金额占比"（按金额）。

## 商品评分分析

按商品统计平均评分：
基于 reviews 表的 score 字段（1-5分），JOIN products 表按商品名称分组计算 AVG(score)。
可按 avg_score DESC 排序找评分最高的商品。

## 库存与销量对比

将 products.stock（库存）与按商品统计的销量（已完成订单数）进行对比，
计算售罄率 = 已售数量 / (库存 + 已售数量)，发现畅销品和滞销品。

## 用户分层

基于消费金额将用户分为：
- 高价值用户：消费金额 ≥ 2000
- 中价值用户：消费金额 500-1999
- 低价值用户：消费金额 < 500
使用 CASE WHEN 语句在 SQL 中实现分层标签。

## 类别占比

各类别销售额占总销售额的比例：
各类别销售额 / 总销售额 × 100%
使用窗口函数或子查询计算总销售额，再计算每类的占比。

## 月度环比增长

比较相邻两个月的销售额变化：
环比增长率 = (本月销售额 - 上月销售额) / 上月销售额 × 100%
需要使用窗口函数 LAG() 或自连接获取上个月数据。
